# Auto Caller

[ English Version ](https://github.com/milad-mma/VOIP-Auto-Caller#readme)

## تماس‌گیر خودکار برای Issabel و Elastix

با استفاده از این ماژول می‌توانید تماس‌های کاملاً خودکار همراه با پیام صوتی دلخواه را به فهرستی از شماره‌ها ارسال کنید. سیستم با Asterisk سازگار است و روی Issabel و Elastix اجرا می‌شود. امکان انتقال تماس به داخلی مشخص (با فشردن ۱ یا ۲ توسط مخاطب)، گزارش‌گیری کامل از نتیجه‌ی هر تماس، و API برای زمان‌بندی و اجرای برنامه‌ریزی‌شده‌ی تماس‌ها هم فراهم شده.

**پیش‌نیاز:** یک ترانک SIP (یا داخلی‌های موجود) برای تماس خروجی. ترانک‌های آنالوگ-به-دیجیتال (gateway) پشتیبانی پایداری ندارند.

## نصب

روی سرور Issabel/Elastix، از طریق SSH:

```bash
wget https://raw.githubusercontent.com/milad-mma/VOIP-Auto-Caller/main/install.sh && chmod +x install.sh && sudo ./install.sh
```

پسورد روت MySQL پرسیده می‌شود. اسکریپت به‌صورت خودکار دیتابیس، کاربر MySQL، فایل‌های پنل (در مسیر `/var/www/html/autocaller`)، دایال‌پلن Asterisk و تنظیمات Apache را می‌سازد.

همین اسکریپت گزینه‌ی **حذف کامل** (گزینه‌ی ۲ در منو) را هم دارد که دیتابیس، فایل‌ها، دایال‌پلن و تنظیمات Apache را به حالت اولیه برمی‌گرداند.

## استفاده

آدرس زیر را (با HTTP، نه HTTPS) باز کنید: `http://[آی‌پی سرور]/autocaller`

![تصویر پنل](https://raw.githubusercontent.com/milad-mma/VOIP-Auto-Caller/main/ISSABEL-Auto-Dialler.jpg)

| فیلد | توضیح |
|---|---|
| Wait Time | مدت انتظار برای پاسخ‌دادن مخاطب (ثانیه) |
| Interval | فاصله‌ی بین هر تماس (بسته به ظرفیت هم‌زمان ترانک) |
| Caller ID | نمایش کالر آی‌دی محلی |
| Prefix | پیشوند شماره‌های خروجی |
| Press 1/2 | انتقال تماس به داخلی مشخص در صورت فشردن این اعداد |
| Upload Number | آپلود فهرست شماره‌ها از اکسل (همراه نام فایل صوتی هر ردیف). ⚠️ ستون شماره تلفن را حتماً با فرمت **متن (Text)** در اکسل تنظیم کنید، وگرنه شماره‌های طولانی به نماد علمی (مثلاً `9.09E+11`) تبدیل و خراب می‌شوند. همچنین مقدار ستون audio باید **دقیقاً** با نام فایل صوتی آپلودشده یکی باشد (بدون غلط تایپی، بدون پسوند). |
| History | گزارش نتیجه‌ی هر تماس، قابل خروجی اکسل |
| Manage Voice | آپلود فایل صوتی WAV/MP3 (ترجیحاً ۸۰۰۰Hz، ۱۶bit، مونو) |
| API | اجرای برنامه‌ریزی‌شده‌ی تماس: `http://[آی‌پی سرور]/autocaller/api.php?action=democall&phone=[شماره]&file=[نام_فایل.wav]&action=call` |

## امکانات

- سازگار با Asterisk (Issabel، Elastix)
- بدون وابستگی به اینترنت هنگام اجرا (بدون فراخوانی CDN یا فونت گوگل)
- زمان‌بندی و اجرای تماس از طریق API
- سناریوی IVR (انتقال با فشردن عدد)
- مانیتورینگ تماس‌های در حال اجرا و گزارش موفق/ناموفق
- امکان چندین تماس هم‌زمان با فایل‌های صوتی مستقل
- ردیابی شماره‌های فعال/غیرفعال در هر کمپین
